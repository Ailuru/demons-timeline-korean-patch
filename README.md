# Demons' Timeline 비공식 한국어 패치

Steam판 **Demons' Timeline**을 한국어로 플레이할 수 있도록 제작한 비공식 팬 번역 패치입니다.

AI 초벌 번역 및 검수에는 **GPT-5.6 Sol**을 사용했습니다.

## 다운로드

**[최신 한국어 패치 다운로드 (GitHub Releases)](https://github.com/Ailuru/demons-timeline-korean-patch/releases/latest)**

Releases 페이지에서 최신 버전의 ZIP 파일을 내려받아 주세요.

## 번역 방향

본 패치는 일본어 원문을 기준으로 하고 영어판을 의미 확인을 위한 보조 자료로 사용했습니다. 한국어 문장을 자연스럽게 다듬되, 일본 SNS와 서브컬처 특유의 문체는 가능한 한 유지하는 방향으로 번역·검수했습니다. 이 때문에 일반적인 한국어 현지화보다 일본어 원문의 어감과 리듬이 강하게 남아 직역처럼 느껴질 수 있습니다.

추리 과정에 영향을 줄 수 있는 부정, 시제, 확실성, 주체, 사건의 선후 관계와 의도적인 모호성은 한국어를 다듬는 과정에서도 바뀌지 않도록 중점적으로 검수했습니다. 반면 한국어로 의미가 잘못 읽히거나 원문의 의도와 관계없이 어색한 표현은 원문과 영어판을 다시 대조해 교정하고 있습니다.

### 문체 판단 기준

- **유지하는 요소:** 원문에 근거가 있는 `~군`, `~짱`, `~님` 등의 일본식 호칭과 관계별 부름말, 일본 문화·오타쿠·서브컬처 용어, 일본 SNS 특유의 짧은 호흡과 여운, 우회적인 표현, 반복과 과장, 말줄임표·전각 문장부호·물결표, 반각 문자·늘임 표기·의도적인 오타·이모티콘·해시태그 등의 표기 장난, 일본 애니메이션풍의 인물별 말투와 리듬은 가능한 한 유지합니다.
- **교정하는 요소:** 한국어에서 의미가 다르게 읽히는 어순, 어색한 조사와 호응, 부자연스러운 일본어식 서술어 결합, 정보량·모호성·논리가 달라진 번역은 교정합니다.
- **피하는 방향:** 일부 문장만 한국 인터넷 은어·유행어에 지나치게 맞추거나, 원문의 말투를 평준화하거나, 원문에 없는 설명과 뉘앙스를 추가해 주변 문체와 동떨어지게 만드는 번역은 피합니다.

## 지원 환경

- Steam Windows판
- 게임 버전: `V1.7`
- Steam App ID: `4198660`
- 확인된 Build ID: `23929782`

지원되지 않는 게임 버전에서는 경고가 표시됩니다. 설치를 계속할 수 있지만 정상 작동을 보장하지 않으므로, 가능하면 지원 버전을 사용하거나 패치 업데이트를 기다려 주세요. 설치 전 원본 게임 파일은 자동으로 백업됩니다.

## 설치 방법

1. Steam에서 게임을 설치한 뒤 한 번 실행하고 종료합니다.
2. [GitHub Releases](https://github.com/Ailuru/demons-timeline-korean-patch/releases/latest)에서 최신 패치 압축 파일을 내려받습니다.
3. 압축 파일의 내용을 `DemonsTimeline.exe`가 있는 게임 폴더에 풉니다.
4. 게임이 완전히 종료되어 있는지 확인합니다.
5. 게임 폴더에 있는 `install.bat`을 더블클릭합니다.

Steam 게임 폴더는 보통 다음 위치에 있습니다.

```text
C:\Program Files (x86)\Steam\steamapps\common\Demons'Timeline
```

Steam 라이브러리에서 게임을 우클릭한 뒤 **관리 → 로컬 파일 보기**를 선택해도 게임 폴더를 열 수 있습니다.

## 원본으로 복원

게임을 종료한 뒤 게임 폴더에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\release_installer\Install-KoreanPatch.ps1 -Action Restore
```

복원이 끝나기 전에는 `.demons-timeline-ko-backup` 폴더를 삭제하지 마세요. 문제가 계속되면 Steam의 **설치된 파일 → 게임 파일 무결성 검사**를 사용할 수 있습니다.
