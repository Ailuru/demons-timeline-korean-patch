# Demons' Timeline 비공식 한국어 패치

Steam판 **Demons' Timeline**을 한국어로 플레이할 수 있도록 제작한 비공식 팬 번역 패치입니다.

추리 게임의 특성상 작은 오역도 풀이를 불가능하게 만들거나 의도하지 않은 힌트를 줄 수 있으므로, 번역문이 원문과 같은 정보량과 논리를 유지하도록 초벌 번역 이후 9단계의 AI 검수 절차를 적용했습니다. 초벌 번역과 검수에는 **GPT-5.6 Sol**을 사용했습니다.

현재 몇 주간의 실제 플레이 테스트와 수동 검수를 진행하고 있습니다. 정식 검증이 끝나기 전에 먼저 플레이하고 싶은 분을 위해 테스트판을 선배포합니다.

## 번역 진행 상황

- AI 초벌 번역 — 완료
- AI 초벌 검수 — 완료
- AI 일본어 원문·영문판 대조 검수 — 완료
- AI 문장 논리·정보량 보존 검수 — 완료
- AI 한국어 문장 품질 검수 — 완료
- AI 원문 대조 품질 교정 — 완료
- AI 용어·말투·문체 일관성 검수 — 완료
- AI 수정본 독립 논리 재검수 — 완료
- AI 퍼즐 기능·풀이 가능성 검수 — 완료
- AI 최종 종합 재검수 — 완료
- **실제 플레이 테스트·수동 검수 — 진행 중**

## 지원 환경

- Steam Windows판
- Steam App ID: `4198660`
- 확인된 Build ID: `23929782`

다른 빌드나 게임 업데이트가 적용된 상태에서는 설치기가 파일을 수정하지 않고 중단합니다. 이 경우 패치의 새 버전을 기다리거나, Steam 콘솔을 이용해 지원되는 구버전을 받아 설치해 주세요.

## 설치 방법

1. Steam에서 게임을 설치한 뒤 한 번 실행하고 종료합니다.
2. GitHub Releases에서 최신 테스트판 압축 파일을 내려받습니다.
3. 압축 파일의 내용을 `DemonsTimeline.exe`가 있는 게임 폴더에 풉니다.
4. 게임이 완전히 종료되어 있는지 확인합니다.
5. 게임 폴더에 있는 `install.bat`을 더블클릭합니다.

Steam 게임 폴더는 보통 다음 위치에 있습니다.

```text
C:\Program Files (x86)\Steam\steamapps\common\Demons'Timeline
```

Steam 라이브러리에서 게임을 우클릭한 뒤 **관리 → 로컬 파일 보기**를 선택해도 게임 폴더를 열 수 있습니다.

설치기는 지원 빌드와 패치 파일의 크기·해시를 먼저 확인합니다. 확인이 끝나면 대상 파일 세 개를 순차적으로 교체하며, 원본은 게임 폴더의 `.demons-timeline-ko-backup`에 보관합니다. 기존 백업은 덮어쓰지 않으며, 설치 도중 문제가 생기면 이미 바뀐 파일도 자동으로 원상복구합니다.

## 원본으로 복원

게임을 종료한 뒤 게임 폴더에서 다음 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\release_installer\Install-KoreanPatch.ps1 -Action Restore
```

복원이 끝나기 전에는 `.demons-timeline-ko-backup` 폴더를 삭제하지 마세요. 문제가 계속되면 Steam의 **설치된 파일 → 게임 파일 무결성 검사**를 사용할 수 있습니다.

## 테스트판 안내

- 현재 실제 플레이 테스트와 수동 검수가 진행 중이므로 오역, 문장 표시 문제, 진행 불가 등의 문제가 남아 있을 수 있습니다.
- 설치기는 게임 데이터 파일 세 개를 수정하지만 세이브 파일은 수정하지 않습니다. 그래도 중요한 세이브 파일은 별도로 백업해 두시기를 권장합니다.
- 게임 업데이트, 다른 모드나 파일 변경과 함께 사용할 경우 설치가 거부되거나 정상 작동하지 않을 수 있습니다.
