# 미확정 사건의 관측자 - Demons' Timeline - 비공식 한국어 패치

Steam Windows판용 비공식 한국어 패치입니다.

**[최신 패치 다운로드](https://github.com/Ailuru/demons-timeline-korean-patch/releases/latest)**

## 지원 환경

- Steam Windows판
- 게임 버전: `V2.1`
- Steam App ID: `4198660`
- 확인된 Build ID: `24925173`

지원되지 않는 게임 버전에서는 경고가 표시됩니다. 설치를 계속할 수 있지만 정상 작동을 보장하지 않으므로, 가능하면 패치 업데이트를 기다려 주세요. 필요한 경우 Steam이 제공하는 콘솔 기능으로 지원 대상 구버전을 내려받아 적용할 수 있습니다.

## 설치 방법

1. Steam에서 게임을 설치한 뒤 한 번 실행하고 종료합니다.
2. [GitHub Releases](https://github.com/Ailuru/demons-timeline-korean-patch/releases/latest)에서 최신 패치 압축 파일을 내려받습니다.
3. 압축 파일의 내용을 `DemonsTimeline.exe`가 있는 게임 폴더에 풉니다.
4. 게임이 완전히 종료되어 있는지 확인합니다.
5. 게임 폴더에 있는 `install.bat`을 더블클릭합니다.
6. 설치가 완료되면 게임을 실행합니다. 언어 선택 화면에서는 아무 언어나 선택해 주세요. 모두 한국어로 표시됩니다.

Steam 게임 폴더는 보통 다음 위치에 있습니다.

```text
C:\Program Files (x86)\Steam\steamapps\common\Demons'Timeline
```

Steam 라이브러리에서 게임을 우클릭한 뒤 **관리 → 로컬 파일 보기**를 선택해도 게임 폴더를 열 수 있습니다.

## 원본으로 복원

1. 게임을 완전히 종료합니다.
2. 게임 폴더의 `restore.bat`을 더블클릭합니다.
3. 확인 메시지에 `Y`를 입력하고 복원 완료 안내가 표시될 때까지 기다립니다.

복원 도구는 설치 시 보관한 검증된 원본 파일만 복원하고 결과를 다시 확인합니다. 복원할 백업을 찾을 수 없거나 복원에 실패하면 Steam의 **설치된 파일 → 게임 파일 무결성 검사**를 이용해 주세요.
